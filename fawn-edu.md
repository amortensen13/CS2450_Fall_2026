## Apollo-11 Repository Facts

- Fact 1: It is written in assembler, specifically a dialect targeting the Apollo guidance computer
- Fact 2: The code in the repository was transcribed from photographs of the source code, which was printed on paper
- Fact 3: There is a [pull request open](https://github.com/chrislgarry/Apollo-11/pull/974/changes) that adds a bunch of tests and CI to run them, which verifies that the assembled output of the code in the repository matches the existing binary artifacts that were deployed on the AGC (or at least, that's what it claims).
