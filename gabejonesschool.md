## Apollo-11 Repository Facts
- Fact 1: 
The respository contains the original Apollo 11 Guidance Computer (AGC) source code for both the Command Module and Lunar Module. The AGC program is also referred to as "Colossus 2A".

- Fact 2:
The source code was digitized by people at the MIT museum and "Virtual AGC". The digitization process included transcription from digitized images of a hardcopy at the MIT museum.

The repository contains 588 commits at this moment
