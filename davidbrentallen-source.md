Apollo-11 Repository Facts



\* The Apollo-11 repository contains the original Apollo Guidance Computer source code for the Command Module (Comanche055) and Lunar Module (Luminary099).

\* The source code was transcribed from digitized images of hardcopies from the MIT Museum.

\* The Apollo Guidance Computer source code in the repository is public domain and lists yaYUL as its assembler.
